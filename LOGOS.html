Anchor to Bitcoin — independent proof of the date

Your device clock proves nothing to a stranger: it can be changed. Anchoring writes your fingerprint into the Bitcoin blockchain through free public calendar servers (no wallet, no account, no payment, no personal data — only the 32-byte fingerprint of your file is ever sent). After that, the date of your file is proven by the whole Bitcoin network, not by you.
Confirmation takes a few hours. Keep the downloaded .ots file next to your original file. After a day, upgrade and check it with the official free client: pip install opentimestamps-client then ots upgrade file.ots and ots verify file.ots. Verify without LOGOS

You never have to trust this program. Any computer on earth can check the same numbers with standard tools:
sha256sum  yourfile          # Linux
shasum -a 256 yourfile        # macOS
certutil -hashfile yourfile SHA256   # Windows

openssl dgst -sha3-512 yourfile      # the SHA3-512 line
If the numbers match the seal, the file is bit-for-bit the one that was sealed. If a single bit was changed, they cannot match.

A proof matters when other people hold it

A fingerprint kept on your own device protects nothing: you could have made it this morning. The moment it is in other hands — in other countries, on other channels — the date is witnessed and the truth can no longer be quietly deleted. Send it to people, not only to institutions. Ten strangers who keep a copy are stronger than one office that files it.

What LOGOS actually does

It computes two cryptographic fingerprints of your file — SHA3-512 and SHA-256 — entirely on your device. A fingerprint is a short number that could only have come from that exact file. Change one pixel, one syllable, one comma, and the fingerprint changes completely. Nobody in the world can build a different file with the same fingerprint.

It then binds that fingerprint to a moment in time and to your words, and hands you the result as a tiny text file — the seal. The seal is the proof. The file stays yours.

What the seal proves

  • Integrity — that a file is exactly, bit for bit, the file that was sealed. This is absolute and permanent.
  • Priority — that the file already existed at a certain moment, provided the seal was made public or anchored at that moment.
  • Attribution — that a named person made a specific statement about that file.

What it does not prove — read this

Honesty is what makes a tool trustworthy, so here are its limits:

  • A seal does not prove the content is true. It proves the file has not been altered since it was sealed. A sealed lie is still a lie — but a sealed truth can no longer be quietly rewritten.
  • The timestamp taken from your device is your own clock, and a clock can be changed. Alone it convinces nobody. It becomes real proof the moment you make the fingerprint public — by anchoring it to Bitcoin, posting it, emailing it, or having anyone else record it. A fingerprint published at a certain date proves the file existed by that date.
  • No software can make a file impossible to delete. Data survives because copies exist in many hands. LOGOS makes the proof so small that it can travel anywhere, and makes any substituted copy instantly detectable. Copying is the survival; mathematics is the proof.

How to make a proof that cannot be erased

  1. Seal the file. Keep the seal.
  2. Anchor it to Bitcoin (one click, free) — the date becomes independent of you.
  3. Send the attestation text to several people, in different countries, on different channels. Post it publicly. Each copy is a full witness.
  4. Keep copies of the original file in several places. The seal proves which copies are authentic.

An adversary would then have to erase every copy, in every country, and break Bitcoin, and break SHA-3. That is the point.

On your phone, and on every computer
