Messagerie privée, appels audio et vidéo et envoi de fichiers, directement entre deux appareils : pas de compte, pas de numéro de téléphone, aucun serveur qui voie jamais un message.

Deux appareils ouvrent une connexion WebRTC privée et se parlent directement, chiffrés de bout en bout. Un petit relais les aide seulement à se trouver et, sur les réseaux très stricts, transmet un trafic déjà chiffré qu'il ne peut pas lire. Aucune base de données ne conserve les conversations. Le relais est un Cloudflare Worker géré par le projet (digitalvalut-turn.burbeng78.workers.dev) ; son code est dans le même dépôt (turn-worker/).

<b>Comment joindre quelqu'un</b>

• Une adresse permanente (DV-XXXX-XXXX-XXXX) qui se vérifie toute seule : c'est l'empreinte d'une clé créée sur votre appareil, une clé substituée est donc refusée
• Jusqu'à huit adresses jetables, chacune révocable séparément
• Un lien d'invitation ou un code QR, que vous pouvez aussi verrouiller avec une phrase dite à voix haute
• Son téléphone sonne même application fermée, sans Google ni Firebase (désactivé tant que vous ne l'activez pas)
• Une lettre scellée pour qui ne peut pas répondre, gardée jusqu'à 7 jours

<b>Savoir à qui vous parlez</b>

À la première connexion, les deux côtés voient le même code de sécurité de trois mots, tiré du véritable échange cryptographique : si les mots concordent, personne n'est au milieu. Les contacts et le blocage ne font confiance qu'à l'identité prouvée par la connexion chiffrée, jamais à un nom déclaré.

<b>Ce qu'elle fait</b>

• Texte, emoji, messages vocaux, photos, vidéos et fichiers jusqu'à 512 Mo, en qualité d'origine
• Les photos perdent leur position GPS et les données de l'appareil avant l'envoi, sans être recompressées
• Appels audio et vidéo, avec partage d'écran
• Partager vers Logos directement depuis n'importe quelle autre application
• Messages éphémères et nettoyage automatique facultatif
• 13 langues, de droite à gauche pour l'arabe et l'ourdou, instructions lues à voix haute et trois tailles de texte

<b>Protections en plus, désactivées tant que vous n'en voulez pas</b>

• Écran protégé : pas de captures d'écran et un aperçu noir parmi les applications ouvertes, contre les logiciels espions et les regards indiscrets
• Cacher où vous êtes : tout passe par le pont chiffré et l'autre personne ne voit jamais votre adresse IP
• Une liste des personnes bloquées

<b>Faite pour être vérifiée, pas crue sur parole</b>

• Son protocole de connexion est écrit et vérifié avec des outils formels (Tamarin, ProVerif, TLA+), qui ont trouvé de vraies attaques, ensuite corrigées
• Reproductible : F-Droid la recompile depuis le code source et obtient le même paquet
• Aucune bibliothèque, aucun script ni CDN tiers ; toute la cryptographie est celle du système (Web Crypto)
• Toute l'application est dans le paquet, ce n'est pas un site dans un cadre : elle fonctionne même quand le site est inaccessible

<b>Limites honnêtes</b>

Pour parler en direct, il faut être connectés tous les deux, mais pas l'appli ouverte : le téléphone sonne même appli fermée, et s'il est éteint, une lettre scellée l'attend. Sans « Cacher où vous êtes », votre adresse IP est visible par la personne à qui vous vous connectez, comme dans toute connexion directe.
